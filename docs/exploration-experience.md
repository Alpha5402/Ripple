# 图谱、导入与证据阅读

图谱标签随缩放分层显示：缩小时优先显示连接较多的笔记，放大后逐步显示全部标签。当前中心始终保留标签；悬停或键盘聚焦节点会突出该节点及一跳邻域，其他元素淡出。选中关系时突出两端笔记，完整标题仍可通过悬停和键盘聚焦查看。此显示策略不改变 Lens、关系集合或语义边界。

通过“打开工作区”选择目录后，桌面端及浏览器先枚举 Markdown 路径，展示各目录纳入、排除数量。父目录数量包含子目录，顶部总数按文件去重。可编辑 gitignore 规则或排除某个目录，确认后才读取纳入内容并构建知识库。取消不切换工作区。桌面端跳过隐藏路径、符号链接和 AGENTS.md；浏览器跳过隐藏路径和 AGENTS.md。统计只反映扫描时存在的 Markdown 文件，不包含空目录；扫描后发生的文件变化以实际导入为准。

已保存的目录句柄可恢复其规则；浏览器不支持目录句柄时使用目录上传，仍先预览再读取文件正文。目录上传无法判断两个同名目录是否相同。排除但从未读取的文本不进入浏览器缓存，之后重新纳入需要再次同步目录。最近工作区直接恢复现有范围；CLI 的显式目录参数保持直接启动。

从图谱选择关系，点击“定位原文”进入只读源码并选中引用片段。点击“返回关系与图谱”或顶部返回按钮，会恢复进入前的视图、原阅读笔记和滚动位置，并重新打开该关系的证据。全局图谱保留镜头状态。直接导航到其他笔记会结束这次临时往返；探索中心的历史返回仍由原有会话管理。

验证包含路径枚举不读取正文、规则例外、父目录计数、真实 Electron 的导入与证据往返，以及浏览器目录句柄适配路径。UI 验证使用隔离 fixture，不能替代大型知识库可读性评估。

执行 `npm run validate:experience` 可重复桌面端回归：使用临时知识库验证预览、排除、标签层级、证据往返、镜头与长笔记滚动位置，截图写入 `reports/local/product-flow/`。需要本机可运行 Electron。
